# 루틴메이트 집중 — Android 테스트 프로젝트

웹사이트: https://bambii0913.github.io/djsfsofdss/

선택한 앱을 열면 접근성 오버레이로 가립니다. 앱 자체를 정지시키지는 않습니다.
수면·디톡스만 적용하며 신체 활동은 제외합니다. 사용 시간 통계는 포함하지 않았습니다.
APK는 아직 빌드되지 않았습니다. 아래 Actions 빌드 후 실제 Android에서 검증해야 합니다.

## 1. APK 만들기 (Android Studio 불필요)

1. GitHub에서 새 저장소 `routine-mate-android`를 만듭니다. 개인 테스트라면 Private을 선택합니다.
2. 이 압축을 풀고 **폴더 안의 내용**을 저장소 최상위에 업로드합니다. 최상위에 `settings.gradle`, `build.gradle`, `app` 폴더가 보여야 합니다.
3. `.github/workflows/build.yml`도 업로드되어야 합니다. Mac에서는 Finder에서 Command+Shift+. 으로 숨김 폴더를 표시할 수 있습니다.
4. 숨김 폴더 업로드가 어려우면 GitHub `Add file → Create new file`에서 파일 이름을 `.github/workflows/build.yml`로 입력하고, 이 프로젝트의 `BUILD-WORKFLOW.txt` 내용을 붙여 넣어 저장합니다.
5. `Actions → Build APK`에서 실행 결과를 기다립니다. 자동 실행이 없으면 `Run workflow`를 누릅니다.
6. 성공한 실행의 `Artifacts → RoutineMate-APK`를 내려받고 압축을 풉니다. `app-debug.apk`를 Android에 설치합니다.
7. Median 앱과는 다른 앱입니다. 이름은 **루틴메이트 집중**입니다. 이후에는 이 앱을 사용합니다.

빌드가 실패하면 Actions의 빨간 단계 로그를 확인합니다. 이 프로젝트는 Java 17 / Gradle 8.11.1 / AGP 8.9.2 / SDK 35를 지정합니다.

## 2. 웹사이트 연결 (필수)

기존 `app.js`와 `rules.js`를 최신 버전으로 다운로드해서 같은 폴더에 놓습니다.
Mac 터미널에서 다음 명령을 실행합니다. 경로는 실제 다운로드 폴더로 바꾸세요.

```sh
python3 /다운로드경로/routine-mate-android/web/patch_web.py /웹사이트코드폴더
```

스크립트는 원본 `.before-native` 백업을 남깁니다. 예상 코드가 없으면 쓰지 않고 중단합니다.
수정된 `app.js`는 GitHub Pages에, `rules.js`는 GitHub Pages와 **실제 API 서버**에 모두 반영해야 합니다.
서버 반영이 안 되면 디톡스가 20초 연결 끊김으로 종료되는 기존 동작이 남습니다.
수면 코인 계산이나 다른 기능은 이 스크립트가 바꾸지 않습니다.

직접 편집하고 싶다면 `MANUAL-WEB-CHANGES.md`를 참고하세요.

## 3. 휴대폰에서 권한 설정

1. `루틴메이트 집중` 상단 **권한 설정**을 누르고 안내에 동의합니다.
2. Android 접근성 설정에서 `루틴메이트 집중`을 켭니다.
3. 설치 경로/Android 버전에 따라 접근성 스위치가 제한될 수 있습니다. 이 경우 해당 앱의 `앱 정보 → 우측 상단 메뉴 → 제한된 설정 허용`이 제공되는지 확인한 뒤 본인이 설치한 앱에 대해서만 허용합니다. 기기 정책으로 금지된 경우에는 진행할 수 없습니다.
4. 앱으로 돌아와 **차단 앱**에서 유튜브 등 테스트할 앱을 선택해 저장합니다.
5. 로그인한 후 **새로운** 수면·디톡스 미션을 시작합니다. 상단 `● 앱 제한 중`을 확인합니다.
6. 선택한 앱을 열어 차단 화면을 확인합니다. 전화 기본 앱·홈 앱·설정·이 앱은 목록에서 제외합니다.
7. **긴급 해제**는 즉시 제한을 풀고 동일한 미션에서 다시 켜지 않게 합니다. 웹 미션의 점수/기록은 종료하지 않으므로 웹에서 별도로 미션을 종료하세요.

## 4. 동작과 한계

- 차단은 웹에서 미션 시작이 확인된 후 약 1초 이내에 켜집니다. 상단 표시를 확인하고 나가세요.
- 미션 종료/신체 활동 전환 시 해제되며, 목표 시간이 지나도 자동 해제됩니다. 웹 미션 자체를 자동 완료하지는 않습니다.
- 최대 24시간을 넘는 잠금은 받지 않습니다. 실제 앱의 수면 목표는 최대 12시간입니다.
- 화면을 꺼도 접근성 서비스와 저장된 마감 시각을 사용합니다. 기종의 절전/서비스 중단/강제 종료에 따라 차단이 풀릴 수 있습니다.
- 접근성 권한 해제·삭제를 막지 않습니다. 재부팅 후 접근성 복구 동작도 기종별 확인이 필요합니다.
- 멀티윈도, PIP, 알림, 제조사 화면은 완벽히 차단하지 못할 수 있습니다. 앱 실행 직후 잠깐 원래 화면이 보일 수 있습니다.
- 화면 내용, 입력 내용, 앱 사용 이력을 읽거나 저장하지 않습니다. 선택한 앱 패키지 목록과 현재 미션 정보만 기기 내부에 저장합니다. 기존 웹사이트의 데이터 처리는 별개입니다.
- 사용 시간 통계, 백그라운드 GPS, 웹 알림, 소셜 로그인 팝업 등 Median 기능을 전부 복제한 프로젝트가 아닙니다. 신체 활동 GPS는 이 버전에 구현하지 않았습니다.
- nativeGuard는 웹이 보내는 값입니다. 악의적인 사용자의 보상 조작을 검증하는 보안/부정행위 방지 수단이 아닙니다.
- 테스트용 debug APK입니다. 여러 번 빌드하면 서명 키가 달라져 이전 테스트 앱을 제거해야 설치되는 경우가 있습니다. 앱 삭제 시 네이티브 설정/웹 로컬 데이터는 삭제됩니다.
- Google Play 배포 심사와 접근성 API 정책 대응은 이 개인 설치 테스트 범위에 포함되지 않습니다.

## 5. 실기기 점검

- 권한 미허용 상태: 제한 중이라고 표시하지 않는지 확인
- 차단 앱 미선택 상태: 제한 중이라고 표시하지 않는지 확인
- 수면 / 디톡스: 선택 앱 차단, 미선택 앱 허용
- 신체 활동: 차단 해제
- 긴급 해제: 즉시 해제되고 같은 미션에서 자동 재잠금되지 않는지 확인
- 미션 종료 / 목표 시간 만료: 해제
- 화면 끄기 후 켜기 / 네트워크 끊기 / 서비스 꺼짐: 실제 동작 확인
- 새 수면 기록의 코인 환산은 별도 서버 보상 코드에 따라 결정됩니다.
